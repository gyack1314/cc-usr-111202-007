# 分流资料

development与holdout均为固定已验证标签样本，subject_id跨两份资料不重叠。score有限，label严格为0或1，weight为正有理数。thresholds用十进制字符串以及-inf/+inf哨兵，按数学大小严格递增；所有并列分数不可拆分。risk_limits针对预先登记的group，任何缺类或缺少整个group都把相应风险记为不可估。

漏检分母包括本group全部真实阳性，假阳性分母包括全部真实阴性，均包括复核区。覆盖率按直接判定权重除总权重。损失是直接判阴阳中的加权错误数分别乘公开费用后的总和，不对复核样本假设复核结果。前沿保留覆盖率和损失均相同的阈值字典序代表，阈值元组按数值序比较。

已有domain只列开发/留出各group的真实标签权重，不选阈值。

## 双阈值分流分析

`triage`命令在拆分前冻结的候选阈值与风险上限下，枚举全人群共享的(lo<=hi)规则：score<lo判阴、score>=hi判阳、其余复核，lo=hi时无复核区，并列分数块整体移动。可行规则要求所有可估登记group同时满足漏检与误报上限，且复核总权重不超过容量；输出覆盖率-损失的Pareto前沿，两指标相同保留阈值字典序最小代表，前沿条目保留每group分子分母证据。选点固定为覆盖率最高、其次损失最低、其次阈值字典序最小，仅在development上进行；holdout只计算该规则的指标与可估性，超限如实展示，不重新挑选阈值。`--max-pairs`资源上限触发时`frontier_complete`为false，结果不得声称完整。无可行规则、全复核与不可估亚组均有明确标记；经验核验不构成总体风险保证。

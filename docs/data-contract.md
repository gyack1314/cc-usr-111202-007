# 分流资料

development与holdout均为固定已验证标签样本，subject_id跨两份资料不重叠。score有限，label严格为0或1，weight为正有理数。thresholds用十进制字符串以及-inf/+inf哨兵，按数学大小严格递增；所有并列分数不可拆分。risk_limits针对预先登记的group，任何缺类或缺少整个group都把相应风险记为不可估。

漏检分母包括本group全部真实阳性，假阳性分母包括全部真实阴性，均包括复核区。覆盖率按直接判定权重除总权重。损失是直接判阴阳中的加权错误数分别乘公开费用后的总和，不对复核样本假设复核结果。前沿保留覆盖率和损失均相同的阈值字典序代表，阈值元组按数值序比较。

已有domain只列开发/留出各group的真实标签权重，不选阈值。
